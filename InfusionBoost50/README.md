# Infusion Boost (+50)

## Description

The strongest tier of Infusion Boost. Vanilla's Hasty, Fortified, Tireless, Sharp, Leeching, Lightweight, Quality, Speedy, and Stacking Speed infusions are bumped to 12.5x their base value, so a piece of Hasty gear grants +50% movement speed instead of +4%, Fortified/Tireless give +50 HP/Stamina instead of +4, and so on. Lightweight's drop chance is capped at 100% rather than the strict math (125%), since it's a probability.

Install this **instead of** the base Infusion Boost or Infusion Boost (+20) mod — they all edit the same infusion values, so only one should be active at a time.

## Installation instructions

1. Install via MOMI like any other mod — no extra setup required.
2. This is a data-only rebalance with no in-game settings menu; the boosted values apply automatically as soon as the mod is installed.
3. Don't install alongside the base Infusion Boost mod or Infusion Boost (+20) — pick one.

## Main features

- Hasty: 4% → 50% movement speed
- Fortified: +4 → +50 HP
- Tireless: +4 → +50 Stamina
- Sharp: +1 → +13 Attack
- Leeching: +1 → +13 HP per hit
- Lightweight: 10% → 100% chance to drop a Stamina orb (capped)
- Quality: +10% → +125% furniture sale value
- Speedy (food): +10% → +125% movement speed for 2 hours
- Stacking Speed (food): +5% → +62% movement speed for 6 hours
- The four unique, non-craftable sword infusions (Venom, Fire, Ice, Instant Kill) are left untouched, since they're tied to specific unique weapons rather than general crafting.
