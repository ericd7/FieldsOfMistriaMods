# Infusion Boost (+10)

## Description

Makes the general-purpose blacksmithing and cooking infusions actually worth chasing. Vanilla's Hasty, Fortified, Tireless, Sharp, Leeching, Lightweight, Quality, Speedy, and Stacking Speed infusions all get bumped to roughly 2.5x their base value, so a piece of Hasty gear grants +10% movement speed instead of +4%, Fortified/Tireless give +10 HP/Stamina instead of +4, and so on.

This is the moderate tier — see Infusion Boost (+20) and Infusion Boost (+50) for stronger alternatives. Install this **instead of** those, not alongside them, since they all edit the same infusion values.

## Installation instructions

1. Install via MOMI like any other mod — no extra setup required.
2. This is a data-only rebalance with no in-game settings menu; the boosted values apply automatically as soon as the mod is installed.
3. Don't install alongside Infusion Boost (+20) or Infusion Boost (+50) — pick one.

## Main features

- Hasty: 4% → 10% movement speed
- Fortified: +4 → +10 HP
- Tireless: +4 → +10 Stamina
- Sharp: +1 → +3 Attack
- Leeching: +1 → +3 HP per hit
- Lightweight: 10% → 25% chance to drop a Stamina orb
- Quality: +10% → +25% furniture sale value
- Speedy (food): +10% → +25% movement speed for 2 hours
- Stacking Speed (food): +5% → +12% movement speed for 6 hours
- The four unique, non-craftable sword infusions (Venom, Fire, Ice, Instant Kill) are left untouched, since they're tied to specific unique weapons rather than general crafting.
